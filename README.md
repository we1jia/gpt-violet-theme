# 紫龙主题（gpt-violet）

给 Claude Code 桌面端换上一套淡紫色主题：薰衣草白的渐变底色，底部几团蓬松的云，侧栏底部一弯紫色月牙和星光，周围点缀星光和紫晶。右侧人物有两套可以切换：

- **御姐版**（默认）：长着龙角、龙翼和龙尾，穿白色荷叶边裙、翘腿坐着的银紫发少女，状态栏显示“💜 紫龙模式 · 星月同行”；
- **Q 版**：穿白紫蓬蓬裙、挥手笑着的 Q 版小紫龙，状态栏显示“💜 小紫龙 · 星月同行”。

## 安装

在 Claude Code 的终端会话里输入：

```
/plugin install gpt-violet --marketplace we1jia/gpt-violet-theme
```

提示添加 marketplace 时输入 `y`，再选择安装范围即可。

## 开关

装好后主题默认开启。在 Code 会话里用斜杠命令随时开关：

- `/gpt-violet q`：换成 Q 版；`/gpt-violet lady`：换回御姐版。会记住选的哪一套，之后的新会话也用这一套；主题关着时换人物会顺手打开。
- `/gpt-violet off`：关掉紫龙主题，换回 App 默认外观；会记住这个选择，之后的新会话也不再自动套用。
- `/gpt-violet on`：重新打开。
- `/gpt-violet`：在开和关之间切换。

App 同一时间只显示一套主题。和蓝鲸主题（blue-whale）同时装着时，新会话里谁最后套上就显示谁；只想用紫龙主题时，先输入 `/blue-whale off` 关掉蓝鲸主题。

## 说明

- 主题只在桌面端和手机 App 的 **Claude Code 会话**里绘制；普通聊天、纯终端和编辑器里看不到背景。
- 只有浅色一套：背景是浅色插画，开启后即使系统是深色模式，也会保持浅色。
- 窗口宽度小于 760 像素时，右侧的人物会自动隐藏，避免挡住正文。
- 背景是静态的，不加动画，避免一直占用 CPU。
- 侧栏的透明度由 App 固定（56%），主题只能改它的颜色和模糊程度；系统开了“降低透明度”或“增强对比度”时，面板会变成完全不透明。
- 卸载：`/plugin uninstall gpt-violet`。

## 实现

背景是纯矢量的 SVG 场景，每套人物一张，由 `tools/build_scene.py` 生成到 `hooks/scene.js`：

- 渐变、云海、弯月、星光和紫晶直接用矢量绘制；御姐版的颜色按 Q 版素材的亮度和饱和度分位整体对齐：衣服头发变白、去掉灰紫、紫色变浅，肤色不动；Q 版本身就是淡紫配色，不调色；
- 人物由 `tools/trace.py` 描摹成分层矢量色块（OpenCV k-means 分色、叠层提取轮廓），因为桌面端的背景场景不显示嵌入的位图。御姐版素材 `tools/source/dragon-girl.webp` 是纯黑底，从四边漫灌抠掉；Q 版素材 `tools/source/chibi.webp` 是透明底，直接用透明通道；
- 脸单独描一层叠在身体上层，用径向渐变遮罩和身体自然过渡，身体层里脸的中心挖掉不重复描；
- 每张 SVG 最多 131072 字符。拆成多张叠画时桌面端会整张背景留空，所以每套人物只用一张，靠省字符换精度：图层按画面里相邻的颜色排在一起叠（同样画面体积小约 20%）。

重新生成（需要 Python 3、Pillow、numpy、opencv-python）：

```
python3 tools/build_scene.py
```

配色和状态栏文案在 `hooks/register.tsx` 里修改。

测试（开关命令、切换两套人物、记住选择、只画自己的场景）：

```
claude plugin test .
```
